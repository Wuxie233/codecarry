# OC Remote v1.6.13 — Release Notes

## Bugfixes

- **Session list filter/search empty state**: if a search/filter yields no matches, the UI now shows a proper "filtered empty" state with a one-tap "Show all" action, instead of pretending there are no conversations at all.
- **Sticky project header overlap**: project folder names no longer render transparently over the list while pinned at the top. Sticky headers now have an opaque background so text does not overlap with underlying rows.

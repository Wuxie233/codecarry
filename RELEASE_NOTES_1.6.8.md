# OC Remote v1.6.8 — Release Notes

Test release focused on a major upgrade to the session list workflow for multi-project usage.

## Highlights

- Added project-based session grouping with sticky headers, collapse/expand state, and pinning support.
- Added a top "Active Subagents" area so background child sessions are visible at a glance.
- Added session list search, filter chips, and sort controls for faster navigation.
- Added project-level actions including create session in project, copy worktree path, and archive-all stub wiring.
- Improved multi-select compatibility across grouped projects.
- Fixed Kotlin/Compose compile issues introduced during the session list integration.

## Notes

- This release is being signed with a temporary test key for device testing.
- If you already have another OC Remote build installed with a different signature, uninstall it before installing this APK.

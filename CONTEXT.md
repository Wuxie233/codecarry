# CodeCarry conversation inputs

Terms for selecting skills while composing a Codex message.

## Language

**Skill**: A named capability available to the current Codex conversation, with a description that helps the user choose it.

**Skill picker**: The searchable list opened by a leading slash in the composer. Selecting an entry prepares a skill attachment for the next message.

**Skill attachment**: A selected skill shown as a removable label beside the draft. It is submitted with the message only when the user presses Send.

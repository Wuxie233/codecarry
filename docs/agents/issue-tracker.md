# Issue tracker

Issues and specs live at https://github.com/Wuxie233/codecarry/issues.
Use gh with --repo Wuxie233/codecarry explicitly.

- Publish a spec: gh issue create; use --body-file for multiline text.
- Read a ticket: gh issue view <number> --comments.
- Find tickets: gh issue list with appropriate state and label filters.
- Update labels: gh issue edit --add-label / --remove-label.
- Close a ticket: gh issue close after the required acceptance checks.
- Read back writes to verify the intended result.

PRs as a request surface: no.
